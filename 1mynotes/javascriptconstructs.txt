🧩 What Are JavaScript Constructs?
In programming, a construct is a building block of the language. In JavaScript, constructs 
include things like:

- Variables & Constants → let, const, var

- Data Types → numbers, strings, booleans, arrays, objects

- Operators → +, -, *, /, ==, ===, &&, ||

- Control Flow → if, else, switch

- Loops → for, while, do...while

- Functions → reusable blocks of code

- Classes & Objects → for structured programming

- Events → responding to user actions like clicks or key presses

📖 Example: Using Constructs with CSS
Let’s extend our responsive navbar with JavaScript. We’ll add a hamburger menu that 
shows or hides links on mobile.

== HTML Update ==
html
<nav class="navbar">
  <div class="logo">MySite</div>
  <button class="menu-toggle">☰</button>
  <ul class="nav-links">
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
    <li><a href="#">Services</a></li>
    <li><a href="#">Contact</a></li>
  </ul>
</nav>

== CSS Update ==

.menu-toggle {
  display: none;
  background: none;
  border: none;
  font-size: 24px;
  color: white;
}

@media (max-width: 600px) {
  .menu-toggle {
    display: block; /* show button on mobile */
  }
  .nav-links {
    display: none; /* hide links by default */
    flex-direction: column;
    background: #444;
    padding: 10px;
  }
  .nav-links.show {
    display: flex; /* show when toggled */
  }
}

== JavaScript Construct Example ==

javascript
// Select elements
const menuToggle = document.querySelector('.menu-toggle');
const navLinks = document.querySelector('.nav-links');

// Add event listener (construct: event handling + function)
menuToggle.addEventListener('click', function() {
  // Toggle class (construct: if/else logic simplified)
  navLinks.classList.toggle('show');
});

== EXPLANATION ==

The Code
javascript
// Select elements
const menuToggle = document.querySelector('.menu-toggle');
const navLinks = document.querySelector('.nav-links');

// Add event listener (construct: event handling + function)
menuToggle.addEventListener('click', function() {
  // Toggle class (construct: if/else logic simplified)
  navLinks.classList.toggle('show');
});
Step-by-Step Explanation
Selecting Elements

javascript
const menuToggle = document.querySelector('.menu-toggle');
const navLinks = document.querySelector('.nav-links');
document.querySelector(...) is a DOM method that finds elements in your HTML.

.menu-toggle means “find the element with the class menu-toggle” (the hamburger button).

.nav-links means “find the element with the class nav-links” (the list of links).

We store them in variables (menuToggle and navLinks) using const.

Adding an Event Listener

javascript
menuToggle.addEventListener('click', function() {
  ...
});
addEventListener tells JavaScript: “When this element is clicked, run the following function.”

Here, the event is 'click'.

The second part (function() { ... }) is the callback function—the code that runs when the click happens.

Toggling a Class

javascript
navLinks.classList.toggle('show');
classList is a property that lets you work with an element’s CSS classes.

.toggle('show') means:

If the element does not have the class show, add it.

If the element already has the class show, remove it.

This is a shortcut instead of writing a longer if/else statement.

Putting It All Together
When you click the hamburger button (menu-toggle), JavaScript runs the function.

That function toggles the show class on the nav-links element.

In CSS, you define what .show does (for example, making the menu visible).

Result: The menu appears and disappears when you click the button.

Analogy
Think of it like a light switch:

menuToggle = the switch.

navLinks = the lamp.

toggle('show') = turning the lamp on or off.

========= Core JavaScript constructs. =========

1️⃣ Variables & Constants
Variables store data you can use later.

javascript
let name = "Christian";   // can change later
const pi = 3.14159;       // constant, cannot change

- Use let when the value may change.
- Use const when the value should stay fixed.

2️⃣ Data Types
JavaScript has different kinds of values:

javascript
let age = 25;             // number
let greeting = "Hello";   // string
let isStudent = true;     // boolean
let colors = ["red", "blue", "green"]; // array
let person = { name: "Christian", city: "Kinshasa" }; // object

3️⃣ Operators
Operators let you do math or logic.

javascript
let sum = 5 + 3;          // 8
let isEqual = (5 === "5"); // false (strict comparison)
let isAdult = (age >= 18 && isStudent === true); // true/false

4️⃣ Control Flow (if/else)
Decide what happens based on conditions.

javascript
if (age >= 18) {
  console.log("You are an adult.");
} else {
  console.log("You are a minor.");
}

5️⃣ Loops
Repeat actions without writing them many times.

javascript
for (let i = 0; i < 5; i++) {
  console.log("Number: " + i);
}
This prints numbers 0 through 4.

6️⃣ Functions
Reusable blocks of code.

javascript
function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Christian")); // Hello, Christian!

7️⃣ Events
React to user actions (like clicks).

javascript
document.querySelector("button").addEventListener("click", function() {
  alert("Button clicked!");
});

8️⃣ Classes & Objects (Intro)
For organizing code.

javascript
class Student {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
  introduce() {
    return `Hi, I'm ${this.name}, age ${this.age}`;
  }
}

let s1 = new Student("Christian", 25);
console.log(s1.introduce());

✅ With these constructs, you can build interactive features like the hamburger 
menu we discussed earlier.
